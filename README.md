# BMI-Calculator-Python

A beginner Python project that calculates Body Mass Index (BMI) based on weight and height.

## About the Project

This program asks the user for their:
- Name
- Weight in kilograms
- Height in centimeters

It then calculates their BMI and displays their BMI category.

## BMI Formula

BMI = (Weight in kg × 10,000) / (Height in cm)²
